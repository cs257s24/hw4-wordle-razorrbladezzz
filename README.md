# How to use
To play:
```
make
./wordle
```
To remove:
```
make clean
```
Instructions provided in the game, works like standard Wordle: 

- Five-letter words only
- Limit 6 attempts
- Must be a real word
- No numbers or special characters 

Green means the letter is in the right spot. Yellow means the letter is in the word, but wrong spot. Grey means the letter is not in the word.

Saying "Y", "y", "Yes", or "yes" will continue the game after winning/losing, anything else will quit the game.

Functions all have comments in the header files describing what they do.
